# JH MAKER 이용·운영 메뉴얼

커스텀 가방·파우치를 **직접 디자인해 주문**하고, 관리자가 **상품·주문·콘텐츠를 운영**하는 웹사이트입니다.

이 문서는 **사이트를 처음 보는 사람**도 따라 할 수 있도록 작성했습니다.  
개발 환경 세팅만 필요한 분은 [9. 개발·배포](#9-개발배포)부터 보시면 됩니다.

## 1. 사이트가 하는 일

JH MAKER는 **완제품 쇼핑몰보다 “맞춤 제작”**에 가깝습니다.

| 역할 | 할 수 있는 것 |
|------|----------------|
| **고객** | 상품 고르기 → 빌더에서 디자인 → 주문 → 마이페이지에서 진행 확인·코멘트 |
| **관리자** | 상품/목업 등록, 주문 확인, 배너·소개글·제작사례 관리, 문의·계정·사이트 설정 |

### 상품 카테고리

| 카테고리 | 예시 |
|----------|------|
| 에코백·토트백 | 크로스백, 보틀백, 토트백, 미니 토트 등 |
| 조리개 파우치·더스트백 | 광목·생지 조리개 파우치 |
| 덮개형·플랫 더스트백 | 덮개형·샤쉐·부직포 더스트백 |
| 지퍼파우치 | 캔버스·타이벡 지퍼 파우치 |
| 부직포 제품 | 다이컷 손잡이 백 등 |
| 기타가방·특수제작 | 백팩·배낭 등 |

## 3. 고객: 처음 주문까지 (따라하기)

### 3-1. 회원가입 / 로그인

1. 우측 상단 **로그인** 클릭  
2. 이메일 가입 또는 카카오/구글 로그인  
3. 처음 소셜 가입 시 약관 동의가 필요할 수 있습니다.

> 비회원으로도 일부 흐름이 가능할 수 있으나, **주문·작업 확인은 로그인 상태**를 권장합니다.

### 3-2. 상품 고르기

1. 상단에서 카테고리를 고르거나 **상품 목록**으로 이동  
2. 원하는 상품 카드 클릭 → 상세 확인  
3. **만들기** / 디자인 시작 버튼으로 빌더 진입  

또는 상단 **나만의 굿즈 만들기**를 누르면 상품 선택 창이 열립니다.  
여기서 카테고리 탭(전체, 에코백·토트백, …)으로 걸러 고를 수 있습니다.

### 3-3. 디자인 후 주문

1. 빌더에서 색상·사이즈·디자인 작업 ([4장](#4-고객-빌더만들기-사용법))  
2. **주문하기**(또는 확인) 진행  
3. 수량·옵션 최종 확인  
4. 결제/입금 안내 절차 진행  
5. **마이페이지 → 주문 상세**에서 접수 여부 확인  

### 3-4. 첫 주문 체크리스트

- [ ] 중요한 로고·글자가 **인쇄 영역(가이드 박스) 안**에 있는가  
- [ ] 이미지가 흐리지 않은가 (가능하면 고해상도 PNG/JPG)  
- [ ] 앞면·뒷면을 각각 확인했는가  
- [ ] 수량·색상이 맞는가

## 4. 고객: 빌더(만들기) 사용법

빌더는 `/builder` 화면입니다. 상품을 고른 뒤 들어옵니다.

### 4-1. 화면 구역

| 구역 | 하는 일 |
|------|---------|
| 가운데 캔버스 | 가방 목업 + 디자인 배치 |
| 앞면/뒷면 탭 | 인쇄할 면 전환 |
| 오른쪽 옵션 | 본체 색, 끈 색(상품별), 사이즈, 수량 등 |
| 도구 | 텍스트 추가, 이미지 업로드, 레이어 순서, 삭제 등 |

### 4-2. 기본 작업 순서

1. **상품이 맞는지** 확인 (다르면 상품 변경)  
2. **색상·사이즈** 선택  
3. **앞면**에 로고/문구 배치  
4. **뒷면**으로 바꿔 필요하면 추가  
5. 인쇄 영역(점선/가이드) **밖으로 중요 요소가 나가지 않게** 조정  
6. 미리보기처럼 전체를 본 뒤 주문  

### 4-3. 이미지 올릴 때

- 권장: **투명 배경 PNG**, 또는 고해상도 JPG  
- 화면에서 괜찮아 보여도, 작은 파일을 크게 늘리면 **인쇄 때 깨질 수 있습니다**  
- 가이드 박스 **안쪽**에 핵심 로고를 두세요  

### 4-4. 텍스트

- 텍스트 도구로 문구 추가  
- 글자 크기를 너무 작게 하면 실물에서 뭉개질 수 있습니다  

### 4-5. 작업 요청 / 코멘트

주문·작업 화면에서 관리자와 메시지를 주고받을 수 있습니다.  
“로고 조금만 위로”, “색 확인 부탁”처럼 **구체적으로** 적으면 수정이 빠릅니다.

---

## 5. 고객: 주문 후 확인·수정 요청

1. **마이페이지** 입장  
2. 해당 주문 클릭  
3. 상태(접수, 작업 중, 완료 등) 확인  
4. 작업물·요청·코멘트 탭이 있으면 거기서 소통  

문의가 일반적일 때는 **1:1 문의** (`/inquiry`) 또는 FAQ (`/faq`)를 이용하세요.

### 제작 기간 안내 (일반적인 기준)

- 접수·디자인 확정 후 제작은 보통 **영업일 3~5일** 전후일 수 있습니다.  
- 수량·옵션·시안 수정 횟수에 따라 달라질 수 있습니다.

## 6. 관리자: 로그인과 메뉴

1. 브라우저에서 `/admin/login` 접속  
2. 관리자 계정으로 로그인  
3. 왼쪽 메뉴로 이동  

### 메뉴별 역할 (짧게)

| 메뉴 | 언제 쓰나 |
|------|-----------|
| 대시보드 | 운영 현황 한눈에 보기 |
| 주문 목록 | 들어온 주문 확인, 상태·작업물 관리 |
| 교환 · 반품 | 고객 교환/반품 신청 목록, 접수·승인·완료 처리 |
| 카테고리 | 상품 분류 이름/노출 |
| 상품 | 상품 정보, 썸네일, 목업(앞·뒤), 상세 |
| 컬렉션 | 홈 등에 묶어서 보여줄 상품 묶음 |
| 배너 | 홈 상단 등 배너 |
| 소개글 | 제작 가이드 / 상황별 굿즈 / **제작 사례** |
| 문의 | 고객 1:1 문의 답변 |
| 계정 | 회원 계정 |
| 설정 | 상호, 연락처, 계좌 등 사이트에 노출되는 정보 |

## 7. 관리자: 상품 등록·목업

### 7-1. 새 상품 등록 흐름

1. **상품 → 상품**에서 새 상품 작성  
2. 이름, 카테고리, 한 줄 설명, 판매 유형(커스텀 등) 입력  
3. **썸네일**: URL 입력이 아니라 **파일 업로드**  
4. 저장 후 해당 상품 상세로 이동  

### 7-2. 목업(앞면·뒷면) — 가장 중요

커스텀 상품은 빌더에 보이는 **실사/컷아웃 이미지**가 필요합니다.

1. 상품 편집 화면의 **목업** 영역  
2. 면 추가(보통 앞면·뒷면)  
3. 각 면에 **이미지 업로드**  
4. **인쇄 영역(박스)**을 드래그해 실제 인쇄 위치에 맞춤  
5. 저장  

> `public/mockups/`에 PNG를 넣은 뒤 DB에 경로를 연결하는 방식도 시드/스크립트로 사용합니다.  
> **새로 올린 `public` 이미지가 엑박이면** 서버(PM2)를 **재시작**해야 할 수 있습니다.

### 7-3. 상세·갤러리

- **상세 · 갤러리** 탭에서 설명 섹션, 갤러리 이미지 등록  
- 갤러리·썸네일도 **파일 업로드** 방식입니다.

### 7-4. 카테고리에 상품이 안 보일 때

- 상품이 **판매중(활성)** 인가  
- **카테고리**가 맞게 연결됐는가  
- 목록/빌더 상품 선택 창은 **카테고리 슬러그** 기준으로 필터됩니다

## 8. 관리자: 주문·콘텐츠·설정

### 8-1. 주문 처리

1. **주문 → 주문 목록**  
2. 주문 선택 → 작업물 / 주문 상세 / 작업 요청 / 코멘트 확인  
3. 필요 시 상태 변경, 고객 요청에 답변  
4. 인쇄용 파일 다운로드가 있으면 제작에 사용  

### 8-2. 소개글 · 제작 사례

**마케팅 → 소개글**

| 유형 | 쓰임 |
|------|------|
| 제작 가이드 | 홈 가이드 영역, `/guides/...` |
| 상황별 굿즈 | 아이디어성 콘텐츠, `/ideas/...` |
| 제작 사례 | 홈 **제작 사례** 섹션, `/cases/...` |

- 커버 이미지는 **파일 업로드**  
- 제목·부제·본문·정렬·노출 여부를 저장하면 홈에 반영됩니다  

### 8-3. 배너

**마케팅 → 배너**에서 홈 히어로 등을 등록합니다.

### 8-4. 설정

**시스템 → 설정**에서 회사명, 연락 이메일, 전화, 계좌 등  
푸터·약관·문의 안내에 쓰이는 정보를 수정합니다.

## 9. 개발·배포

### 기술 스택

| 영역 | 기술 |
|------|------|
| 프레임워크 | Next.js 16 (App Router) |
| 언어 | TypeScript |
| DB | MySQL + Prisma |
| 인증 | JWT 쿠키, bcrypt (카카오/구글 OAuth) |
| UI | Tailwind CSS 4, Lucide |
| 빌더 | Fabric.js |
| 프로세스 | PM2 |

### 폴더 구조 (요약)

```
src/
├── app/                 # 페이지 · API
├── components/          # home, admin, builder, product …
├── lib/                 # DB, catalog, auth, 목업 계산 …
└── types/
prisma/
├── schema.prisma
└── seed.ts              # 카테고리·상품·계정 시드
public/
└── mockups/             # 상품 목업 PNG
```

### 로컬 실행

```bash
# 1) 의존성
npm install

# 2) 환경 변수 (.env)
# DATABASE_URL, AUTH_SECRET, (선택) OAuth·결제 키 등

# 3) DB 준비 + 시드
npm run db:setup

# 4) 개발 서버
npm run dev
```

브라우저: [http://localhost:3000](http://localhost:3000)

### 주요 npm 스크립트

| 명령 | 설명 |
|------|------|
| `npm run dev` | 개발 서버 |
| `npm run build` | 프로덕션 빌드 |
| `npm run start` | 빌드 결과 실행 |
| `npm run db:setup` | `prisma db push` + 시드 |
| `npm run db:seed` | 시드만 실행 |

### 프로덕션 (예시)

```bash
npm run build
pm2 start npm --name jhproject -- start
# 코드/빌드 반영 후
pm2 restart jhproject
```

`public/mockups`에 **새 이미지를 추가한 직후** 404(엑박)가 나면 `pm2 restart`를 한 번 해주세요.

### 상품 시드 보조 스크립트 (참고)

카테고리별로 목업을 넣는 스크립트가 `scripts/`에 있을 수 있습니다.

- `scripts/seed-drawstring-pouches.ts`
- `scripts/seed-flat-dust-bags.ts`
- `scripts/seed-zipper-pouches.ts`
- `scripts/seed-custom-bags.ts`
- `scripts/seed-cases.ts` (제작 사례 더미)

```bash
npx tsx scripts/시드파일명.ts
```

### 현재 제한 사항

- 이메일 알림: `src/lib/notify.ts` — 기본은 서버 로그 스텁 (SMTP/Resend 등 실발송은 별도 연동)
- 업로드 파일: 기본적으로 `public/uploads` 로컬 저장 (S3 미연동일 수 있음)
- 결제: 토스 연동 코드가 있으나, **실키·운영 설정은 환경에 따라 다름**

## 10. 테스트 계정 · 자주 하는 실수

### 시드 후 테스트 계정 (개발용)

시드 실행 시 콘솔에도 출력됩니다.

| 역할 | 이메일 | 비밀번호 |
|------|--------|----------|
| 관리자 | `admin@hmaker.com` | `JhAdmin!2026` |
| 고객 | `customer@hmaker.com` | `JhCustomer!2026` |
| 테스트 고객 | `test@naver.com` | `JhTest!2026` |
| 테스트 관리자 | `test2@naver.com` | `JhAdmin!2026` |

> 운영 환경에서는 반드시 비밀번호를 바꾸거나 테스트 계정을 비활성화하세요.

### 자주 하는 실수

| 증상 | 원인·대처 |
|------|-----------|
| 목업 이미지 엑박 | `public`에 파일은 있는데 서버 미재시작 → `pm2 restart` |
| 빌더에 상품이 안 보임 | 비활성 상품, 카테고리 미연결, 커스텀(saleType) 아님 |
| 인쇄가 잘릴 것 같음 | 가이드 박스 밖으로 중요 요소 배치 |
| 이미지가 흐림 | 저해상도 파일을 크게 확대함 |
| 관리자 메뉴가 안 보임 | 일반 회원으로 로그인함 → 관리자 계정 필요 |
| 홈에 제작 사례 없음 | 소개글 유형 **제작 사례** + 노출(활성) 확인 |
